# Code of Conduct

## Our Pledge

This project is a personal, open-source travel memory tool. Everyone who interacts with this project — in issues, discussions, or pull requests — is expected to be respectful and constructive.

## Standards

Acceptable behavior:
- Constructive feedback and bug reports
- Respectful disagreement
- Helping others with questions

Unacceptable behavior:
- Harassment or personal attacks
- Spam or off-topic promotion
- Deliberately hostile or dismissive communication

## Enforcement

Violations may result in comments being removed or contributors being blocked from the repository.

## Contact

Raise concerns via a GitHub issue or contact the maintainer directly through GitHub.
